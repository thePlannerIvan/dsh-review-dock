# 宿主不解释审阅内容

`dsh-review-dock` 只做四件事：把审阅面放进右侧栏、把字节递给页面、把人的决定原样写进文件、在提交后叫醒模型。被审的是页、是镜、是 Beat 还是一份后端，宿主一概不认，也不许在自己的代码里长出这类知识。代价是宿主不能替页面渲染、不能校验决定的形状、不能判断"某类后端该不该支持命令"——这些全归 `planners-review-core` 和页面自己；换来的是任何新形态的审阅面都不必改宿主。

**后果**：宿主里出现任何"哪些后端存在""哪些字段有意义"的名单，都是这条决定的违例。能力只能问 Core 要答案，不能另抄一份——抄的那一份会和 Core 漂移，而漂移的表现是"按钮亮着、按下去没反应"。
